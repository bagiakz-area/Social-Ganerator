## About

**Social Card Builder** is a browser-based tool for designing custom, animated "Connect Social" cards — the kind you see at the bottom of polished GitHub profile READMEs. Pick an icon, set your username and link, tweak the color theme live, and export your own set of cards ready to drop into your README.

The tool is meant to be used directly from the live site — just visit, customize, and export your own cards.

## Features

- **Live theme editor** — customize border glow, icon color, status color, and background gradient in real time
- **17+ built-in brand icons** — LinkedIn, GitHub, X/Twitter, Instagram, Discord, Spotify, Threads, and more
- **Custom glyph support** — no icon for your platform? Drop in your own text/symbol instead
- **Animated SVG cards** — a subtle glow-sweep animation is baked right into every exported card
- **One-click export** — download your own cards as a `.zip` of individual `.svg` files
- **Ready-to-paste HTML** — auto-generates the exact HTML snippet for your README

## 🛠️ How to Use

1. **Pick a platform** — choose a built-in brand icon, or switch to custom text/glyph
2. **Fill in the details** — title, username, link URL, and status label
3. **Tune the theme** — adjust border glow, icon color, status color, and background gradient live
4. **Add more platforms** — click `+ Add platform` for every social you want to feature
5. **Export your cards**
   - Click **Download all (.zip)** to get your cards as `.svg`
   - Click **Copy HTML Code** to grab the matching HTML snippet

## 📦 Adding Your Cards to Your GitHub README

1. Download the `.zip` and unzip it
2. Place the `.svg` files inside an `assets/socials/` folder in your profile repo
3. Paste the copied HTML snippet into your `README.md`
4. Commit & push — your cards will render directly on your GitHub profile
